# iSpeak: сборка видеоуроков

Здесь живёт только конвейер сборки: рисование кадров, синтез речи, склейка
видео и отправка готовых выпусков в закрытый канал.

Материала курса тут нет. План выпусков приезжает зашифрованным файлом
`plan.json.enc`, ключ хранится в секретах репозитория, а расшифрованный файл
существует только внутри машины сборки и исчезает вместе с ней.

Репозиторий открыт по одной причине: у публичных репозиториев минуты
GitHub Actions бесплатны и не ограничены. Прав на запуск сборки у посторонних
нет, секреты им недоступны, готовые видео артефактами не выкладываются.

## Запуск

```bash
gh workflow run build.yml --repo resmiomar/ispeak-video-builder -f lang=ru -f send=true
```

Десять машин берут по десятой части выпусков. Полная сборка одного языка
занимает около часа, повторная быстрее за счёт кэша озвучки.

## Обновление плана

План собирается в приватном репозитории продукта и кладётся сюда зашифрованным:

```bash
npx tsx scripts/export-video-plan.ts --all
openssl enc -aes-256-cbc -pbkdf2 -in scripts/video/plan.json -out plan.json.enc -pass env:PLAN_KEY
```
